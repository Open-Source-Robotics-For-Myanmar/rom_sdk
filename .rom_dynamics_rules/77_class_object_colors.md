### $\color{cyan}{\text{အရောင်အဓိပ္ပာယ်}}$

| အရောင် | ကိုယ်စားပြုသော တာဝန် |
|---|---|
| အပြာဖျော့ | Abstract interfaces / contracts |
| အစိမ်းဖျော့ | Guidance algorithm နှင့် mission policy |
| လိမ္မော်ဖျော့ | PID objects / control calculation |
| ခရမ်းဖျော့ | Concrete aircraft adapter / ROS I/O |
| အဝါဖျော့ | Runtime / configuration / timers |
| မီးခိုးဖျော့ | State၊ action၊ observations နှင့် telemetry |
| ပန်းရောင်ဖျော့ | Statistics / CSV |
